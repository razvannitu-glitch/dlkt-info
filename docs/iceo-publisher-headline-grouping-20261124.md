# Publisher suffix comparison — 24 November 2026

The exact informative-headline grouping fallback previously included the terminal publisher label in its identity. An otherwise identical title and that title followed by " - HotNews.ro" could therefore occupy two reader cards. This is a code-path finding; the current live prevalence has not been measured.

Comparison now removes only the original publisher's own terminal label, separated by a spaced dash or vertical bar, after the exact reviewed HTTPS origin, canonical URL and publisher label agree. Existing normalized Unicode dashes share the same separator. Foreign labels, unrelated origins, userinfo, invalid canonical paths and inline mentions do not obtain this exception.

This affects only the exact informative-headline fallback. The comparison still includes the rest of the complete title, negations, numbers, summary and subject geography, and retains the fixed two-day reporting window. The existing information threshold is evaluated after the decorative suffix is removed. This does not introduce fuzzy matching or a general semantic-equivalence claim.

Every original card, title, URL, date, attribution and content hash remains unchanged and accessible in the grouped source list. The browser module is generated from the same TypeScript as the server. Tests exercise the positive pair, identity and claim conflicts, short titles, representative changes, paging, source continuation and a subsequent edition. The page/stream expansion that preserves all originals is unchanged.

No request budgets, database schema, permissions, billing or CSS are changed. Publication requires the complete existing release gates, independent review and the official www.dlkt.ee build receipt. Existing improvements that move repeated locale/follow metadata into source details are retained; historical screenshots are not treated as current rendering evidence.
