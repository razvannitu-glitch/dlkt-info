## Verified documentation and remaining evidence gap

The primary [data.gov.sg HDB catalogue](https://data.gov.sg/datasets/d_b51323a474ba789fb4cc3db58a3116d4/view) identifies the four-column aggregate dataset and documents its datastore endpoint. The [official search guide](https://guide.data.gov.sg/developer-guide/dataset-apis/search-and-filter-within-dataset) specifies resource_id, limit, offset, fields and JSON matching filters. The [API overview](https://guide.data.gov.sg/developer-guide/api-overview) documents credential-free testing and recommends an API key in production. The [rate-limit policy](https://guide.data.gov.sg/developer-guide/api-overview/api-rate-limits) lists a public datastore quota; this is not unlimited collection permission. The browser could not retrieve a complete original datastore response in the previous pilot. No new dataset API request was executed for this increment. The envelope decoder is explicitly provisional; its expected success/result/resource_id/records/total shape must be checked against real independently collected bytes before a production adapter can be approved. The tests use deliberately invented prices and ephemeral keys, not observations.

## Gateway

Reuse #111's fixed research context and #110's qualification state. Bind the model, research record, ledger, catalogue packet and statistical/producer period to a SHA-256 context. Define exactly two non-executing request descriptors (one town, 2026-Q2, 4-room, four aggregate columns, limit two, offset zero). The caller must supply a separate Ed25519 public key and evidence class; no key is accepted from a receipt, no trust store or production signing key is installed. Each signed canonical tuple binds the exact request and response URLs, method, status, media type, redirect state, evidence class, time, decoded HTTP entity byte count/hash and source context. Raw decoded entity bytes are validated before parsing; this is not a hash of TLS or compressed wire bytes. Reject altered hashes, signatures, keys, replay across context, future or stale captures, unsupported schema, duplicate JSON keys (including escaped aliases), out-of-filter rows, excessive response size, pagination/cardinality ambiguity and unexpected record fields. Preserve missing/suppressed markers, never infer zero. The 24-hour capture-age and 10-minute pair windows are conservative operator pilot choices, not publisher SLAs or proof of an atomic dataset version.

A valid signature means only that the supplied key signed those metadata; it does not prove that the key belongs to an approved collector, that the remote origin responded, or that a licence or automated access was approved. No independent collector identity, trusted key enrollment, raw remote API receipt, exact currency confirmation or dataset-version coherence exists. A synthetic fixture is always marked synthetic, never upgraded by receipt text. Two signed historical cells cannot prove full data completeness or current market conditions. Results contain hashes and limited aggregate comparison metadata, not raw responses, private data or a publication. The official Q3 watermark stays independent of Q2 transport capture dates. Every output denies probing, activation and publication.

Seven regression groups cover request plans, byte/signature binding, restrictions, transport denial, malformed/ambiguous JSON, row scope, missingness and temporal independence. Exact-head packaging/full CI and independent review remain required. Next gate: resolve collection policy and dataset-specific authorization separately; obtain a bounded independently attributable actual response only after approval, confirm the vendor schema, currency and period against primary evidence, and establish an actual collector trust boundary before any new admission design. Do not merge or deploy this candidate without the existing release gates.
