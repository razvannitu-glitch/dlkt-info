## Bounded operator implementation

The isolated real entrypoint requires a separately supplied Ed25519 reviewer public key and distinct collector private key. A short-lived signed permit binds the exact context, two audit-document digests, exact two pre-existing request descriptors, key fingerprints, one-use nonce, issue/expiry and five ordered source-policy evidence assertions with exact URLs, hashes and review timestamps. The policy hashes are reviewer attestations, not independently fetched or verified by this module; the caller must establish the trust anchors and validate the underlying evidence separately. No embedded key or permit is trusted. The test-only entrypoint always requires synthetic evidence class and accepts an injected fixture transport; the real entrypoint does not accept such a transport or clock. Neither verifies reviewer/collector authority by itself.

An operator-controlled private, non-symlink local directory must already exist. Atomic exclusive nonce reservation (never automatically removed, even on failure) prevents reuse and concurrent execution within that filesystem, not across hosts, compromised local processes or removed/restored ledgers. Real HTTPS transport has a fixed origin/path/filter, two sequential anonymous GET requests maximum, native certificate verification, TLS 1.2 minimum, a ten-second per-request timeout, bounded entity and header sizes, JSON identity encoding only, no redirect, credentials, proxy selection, automatic retry or alternate target. A transport or provisional parser failure prevents the next request. The 15-minute permit, 24-hour review window, 128 KiB entity cap and one-use ledger are conservative pilot choices, not publisher SLAs. Gateway validates and signs decoded entity bytes; the operator receives captures in memory and must store evidence securely if separately authorized. No raw response is logged or published. The provider schema remains provisional until checked against original bytes.

Eight regression groups test synthetic signed permits and receipts, denial, replay/concurrency, expiry, policy and transport failure, directory safety, and separation of synthetic and real entrypoints. No real network call in the tests. Full CI and independent review remain required. Before any real collection: independently establish reviewer and collector keys/authority, verify exact robots/access and licence scope, authorize the bounded research grant, and run in an isolated approved environment. Current Q2 data cannot become current Q3 information through a newer capture date. No automatic source activation or publication is possible through this module.
