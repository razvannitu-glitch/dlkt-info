The raw-body signature verifier accepts a dedicated sandbox endpoint secret, checks HMAC-SHA256 in constant time, bounded body/header, v1 signatures, signed delivery timestamp, event/account/mode/API version and resource route. It deliberately rejects organization context, live mode, invalid and foreign resources. Unknown authenticated event types are ignored. The result is a minimal reconciliation notice, never payment evidence. Webhook signature verification is not a webhook endpoint or durable event processing. Event retries must be deduplicated transactionally before acknowledging actual handling, then authoritative Stripe objects must be reconciled. Use the official Stripe webhook guide https://docs.stripe.com/webhooks#verify-events and subscription guide https://docs.stripe.com/billing/subscriptions/webhooks.
