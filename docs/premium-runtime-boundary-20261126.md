# Premium runtime connection boundary (draft only)
Tracks #65; companion to draft billing PR #67 and lab PR #73, based on current main 375fec4952b3b5b75aab9a59b5491dbf882f451a. Actual server service/API source changes, not a deployment. Default runtime intentionally supplies no billing reader, hence blocks OAuth begin, successful completion, sync and private result access while preserving saved-connection disconnect. Provider public-ready flags remain separate from billing. The server-only dependency contract accepts only a live, reconciled, owner/session-bound, fresh receipt with account/subscription and generation/fence/epoch. Synthetic lab receipts cannot authorize. No JWT metadata or browser input is used as billing proof. The existing verified Supabase session and cookie/PKCE checks remain in place. Recheck at expensive/sensitive boundaries, after provider exchange/refresh/activity and after durable save. Rotated tokens remain encrypted to permit cleanup; a newly obtained unsaved grant is best-effort revoked on failure (not a guarantee of remote revocation). The saved-connection summary hides account label and last-sync time when billing denies, preserving minimal disconnect information. Already-delivered browser data cannot be retroactively revoked; client snapshots clear unavailable provider activity on readback. No UI styling, database, real billing adapter, Stripe operations, provider activation or production change. Actual durable proof reader and current session revocation checks, private server-owned connection persistence/ACL assessment (existing memory store uses user RLS), cancellation and deletion workflows, event linkage, race-safe real payment authorization and real sandbox acceptance remain release gates. No merge while those gates or the fiscal and recovery issues #65/#68 are unresolved. Existing provider test fixtures inject explicit simulated live-shaped receipts only in tests; default export does not inject them. Release manifest and source pin must be generated and checked for exact final source before integration.
