# DLKT Info 0.8.8 — Unified Companion Shell

`/companion-preview` combines Briefing, Trust, Explainable Memory, Actions, Inbox and Delivery in one inspectable loop. It consumes the exact contract created at `/start` rather than rebuilding user preferences.

A valid explicit URL is authoritative. Without explicit URL state, an authenticated user may restore the exact saved contract through same-origin private APIs. No token, secret or private identity enters the URL or browser storage.

The briefing is finite because the user chooses a positive card budget. The product does not hardcode a commercial maximum. A zero-card result is valid and no filler content is invented.

Actions change attention, delivery changes the return path and neither mutates atomic facts. Contradictions remain visible. Source acquisition, notification delivery and public cards remain disabled until their runtime gates are independently activated.
