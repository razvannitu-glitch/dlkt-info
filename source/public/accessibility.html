What the reader supports

The interface uses labelled native controls, keyboard focus indicators, semantic headings and source dialogs. Read updates provides the daily ribbon as a still list. The ribbon starts moving automatically on every page load, including when the device reports a reduced-motion preference. There is no manual playback control. Motion pauses temporarily during touch or desktop hover, while keyboard focus is within the daily-signal section, while a dialog is open or while the page is hidden. It resumes when those conditions end.

Weather illustrations use gentle loops only for a current, supported forecast condition. They become static with reduced motion and pause when hidden, offscreen or covered by a dialog. The layout adapts to narrow screens. Saved choices can be used without a personal account, and failure of browser storage does not stop ordinary reading.

Known boundaries

We do not claim certified conformance to every accessibility standard. External publisher pages and downloadable source documents are controlled by their publishers and may have different accessibility. Moving text should not be your only route to information; use Read updates if following the ribbon is difficult.

Report a barrier

Email office@dlkt.ee with the page, task you were trying, device/browser and any assistive technology relevant to the problem. Share only the information needed to describe it. The same published company contact is available on the contact page.
