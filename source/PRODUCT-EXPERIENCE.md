# DLKT Info 0.8.8 — Exact Companion Handoff

DLKT Info is a finite personal information companion. It does not transfer an infinite feed to the user and does not hide selection, evidence or follow-up rules.

The normal entry begins at `/start`. The user selects topics, exact entities, evidence policy, local delivery time and a positive finite card budget. There is no fixed commercial ceiling of eight entities or twelve cards. Entity configuration is payload-bounded for security; the briefing size is user-defined.

The same visible contract opens immediately in `/companion`. Email OTP is required only when the user chooses cross-device persistence. After verification, the server saves the exact contract atomically and the Companion restores it automatically on another authenticated device. An explicit valid URL always takes precedence over stored preferences.

Trust filtering happens before ranking. Explainable Memory shows every bounded influence. Actions change attention, never truth. Delivery rules change only the return path. Contradictions remain visible and no engine selects factual truth automatically.

A zero-card result is valid. Stable information is not repeated merely to fill the interface. Real acquisition, delivery workers, public cards and commercial release remain behind independent runtime gates.
