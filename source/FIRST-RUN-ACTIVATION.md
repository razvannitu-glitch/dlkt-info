# DLKT Info 0.8.8 — First-Run Activation

`/start` converts four explicit decisions into one strict Companion contract: interests, trust, delivery and final preview.

The user selects at least one information domain and may add exact companies, products, laws, programmes, places or other entities. Entity configuration has no fixed item ceiling; it is protected by per-item validation and an aggregate request budget.

The user chooses an evidence policy, minimum materiality, actionable-only mode, local delivery time and a positive finite card budget. The preview exposes the complete contract before opening the Companion.

The session route uses strict allowlisted URL state and no browser storage. Cross-device save is optional and uses the Activation-to-Account Handoff: email OTP, HttpOnly session, exact authenticated persistence and automatic restoration in `/companion`.
